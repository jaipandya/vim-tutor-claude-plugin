# VimNinja plugins for Claude

This repository is a Claude plugin marketplace with one plugin, [Vim Tutor](vim-tutor/README.md): learn Vim in Claude.
It runs Vim keys on your own text in a real Vim engine, shows the text before and after, and lets you press the same
keys yourself in a small editor in the chat, with practice sets, how-tos, a daily Vim golf hole and a command reference.

Install it in Claude Code:

```
/plugin install vim-tutor --marketplace jaipandya/vim-tutor-claude-plugin
```

What the plugin sends and to whom is in [vim-tutor/README.md](vim-tutor/README.md#data). More about Vim Tutor in other
assistants: https://www.vimninja.com/ai
